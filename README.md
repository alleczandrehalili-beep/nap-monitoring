# NAP Monitoring (AHBA)

Standalone NAP Dashboard (https://nap.ahbadevt.com). Static site served by GitHub Pages; data lives in the AHBA Operations Supabase project (schema `nap`).
Files: `index.html` (dashboard), `nap-core.js`, `nap-api.js`. Copy the three files here from the NAP work and bump `NAP_DASH_VERSION`, the `?v=` tags and `version.json` on every deploy.
